VansonCraft portable mode

While this file sits next to vansoncraft.exe, VansonCraft keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the VansonCraftData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move VansonCraft with its
settings. The first time VansonCraftData is created, any settings already in
%APPDATA%\VansonCraft are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders VansonCraft loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\VansonCraft) instead.
If VansonCraftData can't be written (for example on a read-only drive), VansonCraft logs a
warning and uses %APPDATA%\VansonCraft instead.
