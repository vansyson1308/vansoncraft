# Drawing method: Harold Speed, *The Practice and Science of Drawing* (1913)

Working notes for agents drawing in VectorCraft, taken from a full reading of the book (Project
Gutenberg #14264). Each topic separates what Speed says (principle ids such as `SP-VIII-6` point to
the reading ledger in `docs/speed/`), how to do it with VectorCraft's tools, and where it stops
applying. Read only the topic you need: `vectorcraft://method/{topic}`.

| Topic | Read it when |
|---|---|
| `procedure` | starting any drawing: the order of work and the review loop |
| `line` | building contours and curves; checking a line drawing |
| `mass` | organising lights, half tones and darks; a tone or "mass" study |
| `rhythm` | variety and unity of lines and masses; tying a composition together |
| `balance` | placing masses and the accent; comparing layouts |
| `proportion` | measuring, blocking in, avoiding equal divisions |
| `portrait` | faces and likeness |
| `memory` | drawing from memory and comparing with the reference |
| `materials` | choosing stroke, width profile, hatching and fills for the effect wanted |
| `limits` | what the tools measure, what they cannot, and the author's own warnings |

The study commands (`study.render`, `study.values`, `study.balance`, `study.lines`,
`study.proportions`, `study.compare`, `study.blockIn`, `study.hatch`) measure and draw aids. They
never judge a picture. The brief and the artist's intent come first; a number is a reason to look,
not a target.
