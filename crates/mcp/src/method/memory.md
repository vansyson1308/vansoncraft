# Visual memory

**Speed says.** Memory keeps the essential (SP-XVIII-2) — though memory also reconstructs and
normalises, close to the "dull uniformity" Speed warns of (SP-XVII-4). The faculty can be trained by daily,
graded memory drawing, after Lecoq de Boisbaudran (SP-XVIII-5). Enjoy the subject, then study it as
a flat impression: the proportions of its main lines, their shapes and their placing, and draw it in
your mind in the terms of your medium; then draw it (SP-XVIII-4, SP-XVIII-6). Decide the scheme at
first sight and don't switch for novelty (SP-XVIII-8).

**With VansonCraft (a practice workflow the agent runs for a person, not a test).** Hiding a layer
does not take the reference out of an agent's context: an agent drawing "from memory" for itself
has already seen it and must say so.
1. Place the reference on a template layer named "Reference"; look at it with
   `render_preview {showTemplates: true}`.
2. Hide it: `layer.setProps {id, visible: false}`.
3. The person draws the subject from memory on its own layer.
4. When asked, show the reference again and compare: overlay with `showTemplates`, and
   `study.compare {a: drawing, b: reference shape, image: true}`, which comes back as a red/blue
   difference map of the silhouettes.
5. Note what was remembered and what was not, in words; draw again another day.

**More from the book.**

- References colour what you see and draw (SP-XVIII-1). Study them for their qualities; never copy them into the deliverable. Use only references the user may use.

**Limits.** This is an observation exercise. Nothing here measures a person's memory or cognitive
ability, and the comparison measures silhouettes, not drawing quality.
